ラインクラフトの遊び方

ラインクラフトで遊ぶ

version 0.1 / 2026-09-27

1行コンセプト

「場に並ぶ3枚のタイルから1枚を選び取り、盤上の4x4マスに置いて、縦・横・斜めの合計値で相手より勝るラインを1本でも多く作る」2人用の短時間アブストラクトゲーム。

基本情報

  • プレイ人数: 2人（対人戦・AI対戦の両対応）
  • プレイ時間: 約10〜15分
  • 対象年齢: 8歳以上
  • ジャンル: アブストラクト戦略・ドラフト＆プレイスメント

コアループ

  1. 場（マーケット）に並ぶ3枚の数字タイルから1枚を選んで取る
  2. 盤面4x4の空いているマスに好きな場所に置く（自分の色として記録される）
  3. マーケットを山札から補充する
  4. 手番交代

これを盤面が埋まる（16マス）まで繰り返し、最後に縦4本・横4本・斜め2本、合計10本のライン上で自分の置いた数字の合計が相手より大きいラインの数を競う。

コンポーネント一覧

コンポーネント 数 説明
数字タイル 16枚 値は1・2・3・4がそれぞれ4枚ずつ
盤面 1枚 4x4マス（16マス）
プレイヤーマーカー（色） 2色 どちらが置いたタイルかを示す

セットアップ

  1. 16枚のタイルをよくシャッフルし、山札にする（デジタル版ではシード値付き乱数で再現可能）。
  2. 山札の上から3枚を表向きにしてマーケットに並べる。
  3. 盤面（4x4マス）を空の状態で用意する。
  4. 先手（プレイヤー1）を決める（デジタル版ではプレイヤー1固定、もしくはコイントス相当のランダム決定）。

手番順（スネークドラフト）

単純な「交互手番（P1→P2→P1→P2…）」だと、毎回先にマーケットを覗けるプレイヤー1が構造的に有利になることがテストで分かった。これを緩和するため、本ゲームは4手を1ブロックとしたスネークドラフト順を採用する。

P1, P2, P2, P1, | P1, P2, P2, P1, | P1, P2, P2, P1, | P1, P2, P2, P1

16手をこの順で行うと、各プレイヤーはちょうど8手ずつ担当し、かつ「連続して先に選べる回数」が均等になる。覚え方は「1人ずつ→2人ずつ交代」で難しくない。

ターンの流れ

手番プレイヤーは以下を この順番で 行う。

  1. ドラフト: マーケットに並ぶ最大3枚のタイルから1枚を選んで手に取る。
  2. 配置: そのタイルを盤面の空いている任意のマスに置く。置いたタイルは自分の色になる（一度置いたタイルは動かせない・裏返せない）。
  3. 補充: 山札の一番上のタイルを1枚めくり、マーケットの空いた枠に補充する。山札が尽きている場合はマーケットの枠が減ったまま（3枚→2枚→1枚→0枚）続行する。
  4. 手番はもう一方のプレイヤーに移る。

同時手番は存在しない。プレイヤー1とプレイヤー2が交互に手番を行い、各プレイヤーはゲーム終了までにちょうど8枚ずつ配置する（16マス÷2人）。

終了条件

盤面の16マスすべてが埋まった時点で即座にゲーム終了。タイルは16枚しかなく、1マスに1枚しか置けないため、ゲームは必ずちょうど16手（各プレイヤー8手）で終了する。無限ループや手詰まり（置ける場所がない状況）は構造上発生しない。

得点計算

盤面には合計10本のラインが存在する。

  • 横ライン: 4本（各行）
  • 縦ライン: 4本（各列）
  • 斜めライン: 2本（左上→右下、右上→左下）

各ラインについて、そのライン上にある4マスのうち、プレイヤーAが置いたタイルの数字の合計と、プレイヤーBが置いたタイルの数字の合計を比較する。

  • 合計が大きい方が、そのラインを1点獲得する。
  • 合計値が同じ場合、そのラインは引き分け（どちらにも点数は入らない）。
  • 1マスも自分のタイルがないラインは合計0として扱う。

10本のライン点を集計し、ライン点数が多い方の勝ち。

タイブレーク（ライン点数が同点の場合）

  1. 盤面全体で自分が置いたタイルの数字の合計値（総和）が大きい方が勝ち。
  2. それも同値の場合は「引き分け」を正式な結果とする（無理に決着をつけない）。

プレイ例（冒頭2ターン）

  1. マーケット: [3, 1, 4]。プレイヤー1は「4」を取り、盤面の中央寄りのマス(1,1)に置く。マーケットが[1, 2]→補充で[1, 2, 2]になる（山札の次が2だった場合）。
  2. マーケット: [1, 2, 2]。プレイヤー2は「2」を取り、(1,1)と同じ行のマス(1,3)に置いて、その行でのプレイヤー1優位を早めに削りにいく。マーケットは[1, 2]→補充される。
  3. 以降同様に、8ターンずつ交互に繰り返し、16マスが埋まったら得点計算を行う。
